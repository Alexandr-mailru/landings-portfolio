# ATRIUM — тема WordPress

Премиальная тема для архитектурного бюро. Учебный проект для портфолио.

## Что внутри

- Кастомный CPT `atrium_project` + таксономия «Типология»
- Customizer: слоган, контакты, ссылка на политику ПДн
- AJAX-форма заявки с обязательным согласием (152-ФЗ на уровне сайта)
- Шаблоны: главная, страница, одиночный проект
- Адаптив, доступное меню, reduced-motion

## Установка (Local / хостинг)

1. Поставьте WordPress 6+.
2. Скопируйте папку `atrium` в `wp-content/themes/`.
3. Внешний вид → Темы → активируйте **ATRIUM**.
4. Настройки → Чтение → «Статическая страница» → создайте и назначьте главную.
5. Создайте страницу «Политика ПДн» со слагом `privacy`.
6. Внешний вид → Настроить → ATRIUM — бренд и контакты.
7. Добавьте проекты: Проекты → Добавить (обложка + год/площадь/локация).
