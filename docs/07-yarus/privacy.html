Политика обработки персональных данных

Учебный демо-проект для портфолио (HTML + GSAP). Логика соответствует ФЗ‑152. Это не коммерческий сервис: форм сбора данных на сайте нет.

1. Какие данные собираем

Не собираем. Анимации работают в браузере, без отправки заявок на сервер.

2. Cookie и сторонние скрипты

Аналитика не подключена. Подключаются Google Fonts и CDN GSAP (jsDelivr). Сторонние cookie рекламного назначения не используются.

3. Права

Для реального сервиса здесь указывают контакты оператора. В демо персональные данные не обрабатываются.
