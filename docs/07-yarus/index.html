Сборка, нарисованная кадр за кадром

Листайте — торт наращивает ярусы, дом поднимается от фундамента. Каждый кадр генерируется на лету.

Смотреть сборку

Скролл = кадр

Как сделано

Не сток-видео. Свои кадры, один стиль, плавный scrub.

Движок рисует сцену на Canvas по прогрессу скролла: сотни промежуточных состояний без скачков между чужими роликами.
